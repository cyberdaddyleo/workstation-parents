# 学生家长工作台 v1.0 使用指南

这是给家长使用的本地成长记录工具。日常记录无需账号，也不需要联网；可选 AI 功能另行配置。软件采用自定义使用许可，个人与家庭可免费使用，商业使用须取得作者书面授权，详见 [LICENSE](../LICENSE)。

## 1. 下载并打开

项目地址：[cyberdaddyleo/workstation-parents](https://github.com/cyberdaddyleo/workstation-parents)。

- **不会用 Git**：打开项目页面，点「Code → Download ZIP」，下载后先解压。
- **已安装 Git**：在准备存放项目的文件夹打开终端，执行：

  ```bash
  git clone https://github.com/cyberdaddyleo/workstation-parents.git
  ```

用 Chrome 或 Edge 打开项目中的 `index.html`，可以双击，或拖进浏览器窗口。不需要 `npm install`，也不需要启动开发服务器。请保留整个下载包中的说明和许可文件。

记录保存在当前浏览器的本地存储中，不会因为下载了同一个文件就自动同步。建议固定使用同一浏览器、同一浏览器用户配置和同一文件位置；换电脑、浏览器或位置前先备份。不要用无痕窗口长期记录。

## 2. 第一次选哪种模式

欢迎页先选「妈妈 / 爸爸」，填写「怎么称呼你」，再选模式。

**「记录我的孩子」**适合直接开始。点击「下一步」，选择女孩或男孩，以及幼儿园、小学低年级、小学高年级、初中、高中中的一个阶段。下一页只有「名字 / 小名」必填；生日、身高、体重、学校和近况可以稍后补。确认年级后，点「开启成长之家」。

**「先看看示例」**适合熟悉界面。选择阶段后点「看看示例」，系统会生成一个虚拟的两孩家庭，包含历史打卡、日程、关系网和成长记录。孩子姓名、学校、身高等只是演示资料。

两种模式都使用阶段推荐，但含义不同：示例模式会生成虚构的历史记录；真实录入模式只为新孩子开启推荐打卡项等初始内容，不会把示例家庭的历史带进去。推荐内容也不等于必须完成的任务，可以按家庭实际情况调整。

## 3. 从示例切换到自己的家庭

先到「设置 → 数据与备份 → 导出备份」，尤其是已经在示例里试填过信息时。确认文件已下载后，点侧栏「开始记录我的孩子」，再确认「清空并开始」，按弹出的表单添加自己的孩子。

也可以使用「设置 → 数据与备份 → 清空全部数据」。这会删除孩子及其记录和 AI 对话，随后进入添加孩子的位置。两种清空方式都会保留家庭与 AI 设置；要移除 API Key，请另到「设置 → AI 接口」清空对应字段。

在「设置 → 家庭」修改家长身份和称呼；要同时显示另一位家长，在「家里的另一位家长」勾选「在家里显示」，填写称呼并选择形象。

在「设置 → 孩子」点「添加孩子」或已有孩子旁的「编辑」。除了名字、阶段、性别和生日，还可以填写「学校」「年级」「班级 / 班主任」；后者是两个输入框，分别填班级与老师称呼。兴趣、性格、健康注意和备注按需填写，点「添加」或「保存」。成长档案中的「编辑资料」也能打开孩子资料表单。

每个孩子单独记录，操作前先核对页面顶部选中了谁。升学后修改阶段与年级，原有打卡和技能会保留；新阶段的习惯到「五育打卡 → 从推荐里添加」自行挑选。

## 4. 每天怎么用

- **成长之家**：看今日清单与日程，完成后打卡；睡前切到「睡前小结」，一起回顾一天。
- **成长日历**：用「新日程」安排学习、运动、兴趣班或亲子活动，固定活动可设每天或每周重复。「导出到手机日历」生成 `.ics` 文件，需要自行导入其他日历，并非自动同步。
- **五育打卡、学习力、技能挑战**：先保留少量适合孩子的习惯；按需要记学习计划、阅读、能力观察和技能步骤。学校成绩只是学习力的一部分。
- **关系网、成长档案**：记下身边的人与生日；用「记一刻」记录心情、小事和第一次，用「量身高体重」补充测量记录。

每周看一次「本周五育」，和孩子讨论下周想尝试什么；定期导出备份。建议睡眠、成长提示和 AI 回答仅作一般参考，不能替代专业判断。

## 5. 配置 AI：可选

不用 API Key 也能在模板中点「复制提示词」，自行检查后粘贴到外部 AI 网页或 App。复制出去的内容同样可能包含家庭资料。

要在工作台直接生成，打开「设置 → AI 接口」，选择「服务商」，填写自己的「API Key」，核对「接口地址（Base URL）」和「模型名称」，再点「测试连接」。测试会实际调用模型，是否收费以服务商规则为准。预设模型名只是默认值，以你的控制台实际可用模型为准；切换服务商后也要核对 Key。

普通兼容接口会自动在 Base URL 后拼接 `/chat/completions`，Claude 接口会拼接 `/messages`，不要重复填写完整终点路径。例如 DeepSeek 的 Base URL 可填 `https://api.deepseek.com`。Ollama 需先在本机运行模型并允许网页访问，再选择对应服务商和已安装模型；本地模型可以不填 Key。

若遇到浏览器跨域限制，安装 Node.js 18 或更高版本，在项目文件夹运行：

```bash
node ai-proxy.js
```

保持终端运行，把 Base URL 改为本地代理前缀加原地址，例如：

```text
http://127.0.0.1:8787/https://api.deepseek.com
```

模型名称不变，远端服务需要的 Key 仍需填写。用完在终端按 `Ctrl + C` 停止。代理只监听本机，不保存请求内容；请求仍会转发给配置的服务商。代理不能解决错误模型名、无效 Key 或额度不足。

## 6. 备份与隐私边界

「导出备份」下载 JSON 文件，包含家庭记录、AI 对话和接口配置，**包括明文 API Key**。请私下妥善保存，不要提交 GitHub、发到公开群或交给 AI 工具读取。

迁移时，在新环境打开工作台，到「设置 → 数据与备份 → 从备份恢复」选择 JSON，核对提示后恢复。**恢复会覆盖当前全部数据，不会合并**，先备份目标环境中需要保留的记录。

普通记录保存在本地。清理浏览器数据会丢失记录；若浏览器禁用本地存储，程序只能暂存在内存，关闭页面后无法保留，应及时导出。

使用 AI 时，问题、对话与相关成长资料会发给你配置的服务。模板和上下文可能包含健康注意、日记、习惯等信息，类别开关不代表严格隔离。当前 v1.0 的「隐去名字」存在遗漏：部分正文会替换姓名，但系统提示仍可能带上家长称呼和孩子真名。它也不会完整遮蔽学校、联系方式或自由填写的敏感信息；不要将其视为完整匿名化保障。
